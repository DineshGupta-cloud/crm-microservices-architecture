# Testing Prompt

Act as a senior QA engineer.

Feature/API:
[FEATURE]

Create a test matrix covering:
- happy path
- required field validation
- invalid input
- boundary values
- duplicate records
- not found
- unauthorized
- forbidden
- persistence failure
- pagination
- filtering/search
- concurrency/retry cases where relevant
- service-to-service failure where relevant

For each test provide:
- test name
- setup
- request/input
- expected result
- HTTP status where applicable

Then identify missing automated tests.
