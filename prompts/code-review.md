# Code Review Prompt

Act as a senior production code reviewer.

Review:
[CODE OR DIFF]

Check:
- correctness
- bugs
- null handling
- exception handling
- SOLID/Clean Code
- duplication
- API design
- database efficiency
- transactions
- concurrency
- logging
- maintainability
- tests
- backward compatibility

Classify findings:
CRITICAL
IMPORTANT
OPTIONAL

Do not recommend rewrites unless they provide meaningful value.
